# AI 翻译界面 V2 设计提案

状态：用户已于 2026-11-16 确认设计，Rust 界面已实现；原生交互验收受窗口自动化超时阻碍，详见实施计划。

[交互预览](2026-11-16-ai-translate-ui-v2.html)

## 目标

用户的主要任务是输入文本、确认语言、得到译文。日常操作保持一眼可见，连接和模型配置按需进入设置。保持上下分区、交换文本、Enter 翻译及 Shift+Enter 换行。

## 当前问题

1. 语言使用固定宽度的 `Select`，名称与箭头相距较远，更像设置表单，抢占文本区的视觉权重。
2. 底栏直接展示模型名，在空间不足时变成 `deepseek…`；既不能识别完整配置，也不能据此完成模型切换。
3. 只有通用／技术两种风格，却使用较宽的下拉框，隐藏了另一个选择。
4. 修改内容后，同时显示「上次译文 · 与当前请求不一致」和「原文或配置已改变」，重复表达同一状态。

## 方案取舍

| 方案 | 收益 | 代价 | 结论 |
| --- | --- | --- | --- |
| 语言用紧凑菜单，风格用分段按钮，配置进入设置 | 翻译过程只保留必要决策，所有常用操作可直接触达 | 需要打开设置查看模型 | 用户已批准，本稿采用 |
| 保留当前布局，只减小宽度和字号 | 改动少 | 模型信息与操作混杂，仍然像表单 | 不推荐 |
| 风格和模型全部收进设置 | 工作区最简洁 | 技术／日常切换多一步，不符合目前使用场景 | 暂不采用 |

## 具体设计

### 语言菜单

上下两区各自设置独立控制栏，左侧明确标注「原文语言」与「译文语言」。原文选择显示「自动检测 ▾」「英语 ▾」或「简体中文 ▾」；自动检测时在旁边以次要文字显示「已识别英语／中文」。上下语言控件保持同一条左对齐线。

语言选择使用始终可见的浅背景、细边框和下拉箭头，明确表达「可点击的选项」。保持紧凑宽度，不横向拉伸；菜单展开宽度独立于触发按钮，容纳完整选项。悬浮加强背景与边框，焦点和展开态可辨认。

控制栏底部用一条细线与文本编辑区域分开，正文从下一行开始。按用户实机反馈，文本区不显示整圈彩色焦点边框，以光标与选区标明编辑位置；语言菜单和按钮仍保留组件标准的键盘焦点样式。

继续只有中英两种语言；不增加新语言、翻译供应商或模型能力。

### 文本与分隔

沿用一个上下分区内容框。原文区白底／主题背景，译文区使用主题弱背景；不增加嵌套卡片。正文及控件共享左侧内容边线。

原文右上并列「复制原文」和「清空」图标，译文右上提供「复制译文」，均沿用共享图标按钮并给出明确的悬浮提示和无障碍名称。复制按钮复制各自区域当前全文；对应内容为空时禁用，不依赖翻译是否完成。普通选择复制仍保留。

字符计数放到原文右下，键盘提示在左下，用次要字号。圆形交换按钮位于译文语言栏的水平与垂直中心，与语言选择和复制按钮对齐，悬浮提示「交换原文与译文」。按钮交换上下文本；分隔线仍用于拖动调整分区。

中间区域采用紧凑间距：原型中提示行约 20 px，译文语言栏约 40 px，合计约 60 px；取消为交换按钮额外预留的顶部空白。上下语言栏统一高度，保持下拉按钮 30 px、图标按钮 28 px 的可点击尺寸，缩减的空间留给正文。交换按钮完整放在译文语言栏内，不压住分隔线，也不额外占据一行。

### 底栏

从左至右为：设置齿轮、通用／技术分段按钮、弹性留白、翻译按钮。

齿轮悬浮为「设置」，直达 AI 翻译设置。风格分段按钮只突出当前选中项，随时能看到另一个选项。主要动作保留文字，运行中变为停止。

工作区不再常驻展示模型名；完整模型、endpoint、Key 来源在现有设置页查看和修改。这里没有需要重复展示的多供应商选择器。

### 状态

正常完成：内容本身即反馈，不额外增加「翻译完成」一行。

原文或设置改变：目标语言旁仅显示「待重新翻译」，保留旧译文；不在底部重复同一提示。复制动作仍说明复制的是旧译文。

进行中／停止：目标语言旁显示「正在翻译」或「未完成」。

失败：译文下方显示一条具体错误和恢复办法，主按钮变为重试。未配置 Key：同一区域提供「配置 DeepSeek…」入口；原文保持可编辑。

## GPUI 落地约束

- 语言使用标准菜单组件及紧凑触发按钮，复用其键盘导航、选中标记、Escape 和焦点恢复；不要自己画弹出列表。
- 风格使用现有按钮组／分段控件。设置、清空、复制继续使用 `Toolbar::button` 和 `ButtonExt`。
- 尺寸跟随 rem、组件 Small 及主题语义色。原型的 800×600、640 px 宽度用于预览，不能把 CSS 数值逐个搬进 Rust。
- 不修改翻译请求、Key 存储、协议和错误映射；本次仅重组控件与状态呈现。
- 保留现有输入法保护、选区复制、原文撤销、任务取消和分离窗口生命周期。

## 验证边界

原型可预览深浅色、两种宽度、语言选择、风格选择、上下文本交换、拖动分区和固定示例流式播放；不联网，不读取或保存 Key。

原型已做 HTML 引用与 JavaScript 语法自检。Rust 实现已通过编译、Clippy 和相关测试，但窗口自动化尚未完成翻译页操作，因此真实 GPUI 的鼠标命中、640／800 px、12–20 字号、深浅色和输入法行为仍需实机验收。
