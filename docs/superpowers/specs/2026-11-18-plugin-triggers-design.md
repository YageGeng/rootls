# 启动器插件搜索与触发词

触发词由插件开发者在代码中声明，随插件发布。用户在启动器里输入名称、触发词或待处理的文本，列表随输入更新，默认选中最合适的插件。按 Enter 或点击某一行才打开插件。

## 输入与打开行为

| 启动器输入 | 默认选中 | 确认后的行为 |
| --- | --- | --- |
| 空输入 | 按现有顺序列出全部插件，选中第一项 | 打开选中的插件 |
| `json` | JSON 编辑器 | 打开已有编辑页或草稿 |
| `trans` 或 `fy` | 翻译 | 打开翻译页，沿用已有会话 |
| `diff` | 文本对比 | 打开对比页 |
| `jqb` | 剪贴板历史 | 打开历史列表 |
| `剪贴`、`fanyi` 或 `compare` | 按名称和现有关键词匹配的插件 | 按名称打开 |
| `{"text":"fy"}`、`[1,2]`、`"hello"`、`true`、`123` 或 `null` | JSON 编辑器 | 将完整原文交给编辑器 |
| `Please translate this sentence.` | 翻译 | 将原文填入翻译页，由用户发起翻译 |

触发词按整段匹配，忽略首尾空白和英文字母大小写，` FY ` 与 `fy` 等价。对于 `{"text":"fy"}`，`fy` 是 JSON 数据的一部分。用户手动选择翻译时，翻译页收到整段 JSON。

## 匹配规则

插件在现有 `PluginManifest` 中声明 `triggers`。本地化名称、稳定 ID、触发词和现有 `keywords` 共同用于列表搜索。内置注册表的测试从应用使用的插件清单读取声明，检查空词和归一化后的重复触发词，报错给出冲突词和插件 ID。普通搜索关键词可以重合。[插件契约与注册表](../../../crates/rtools/src/plugin/mod.rs)

注册表为每个插件保留最佳的一项匹配。以下顺序决定列表的默认选中项。

1. **完整触发词**，例如 `FY` 匹配翻译。
2. **已识别的内容**，例如可完整解析的 JSON。JSON 编辑器对对象、数组和单值使用同样的优先级。
3. **插件搜索**，按名称、ID、触发词和关键词查找。完整匹配排在前缀前，前缀排在其他子串前。
4. **格式线索**，例如尚未写完的 `{"a":`。JSON 编辑器可作为修复候选，行内提示表达“可用 JSON 编辑器打开”。现有 XML、URL 参数和多行 YAML 的入口继续由 JSON 插件提供。
5. **通用文本**，翻译可以接收非空文本，在更精确的匹配之后出现。

同级且匹配程度相同的结果沿用注册顺序。将翻译注册在 JSON 之前，也应得到相同的 JSON 默认选项。整段输入只有空白或开头的 BOM 时按空输入处理。设置和退出在系统分组中响应普通搜索。

## 搜索词与原文

短单行输入可以直接编辑。多行粘贴或超过 4 KiB 的粘贴沿用现有的内容标签。标签保存原文，搜索框按触发词、名称和关键词筛选能接收这段原文的插件，完整触发词排在第一位。先粘贴多行 JSON 时默认选中 JSON，接着输入 `fy` 会选中翻译，按 Enter 传入整段 JSON。输入 `jqb` 时，此候选集为空，标签仍保留。清除筛选词即恢复全部可用候选，清除标签则回到普通插件搜索。[粘贴入口](../../../crates/rtools/src/launcher/paste.rs)

由匹配结果同时给出排序依据和启动时的数据来源。单独输入触发词或名称时，启动器传入 `Launch.input = None`。选中内容处理动作时，取搜索框的原文或标签中的原文传入 `Launch.input`。大小写归一化仅供搜索使用。方向键、鼠标和 Enter 都使用同一份结果。[启动器选择与打开](../../../crates/rtools/src/launcher/mod.rs)

## 实现取舍

触发词随插件发布，词表与对应插件放在一起。排序归 `PluginRegistry`。支持处理原文的插件通过 `Plugin::recognizer` 返回纯识别函数。匹配结果保存“已识别”“格式线索”或“通用文本”级别及对应的翻译键，列表按当前界面语言展示理由。切换语言时复用识别结果。

启动器与编辑器共用格式判断，支持 JSON 对象、数组、字符串、数字、布尔值和 `null`。含重复键的对象和残缺的 JSON 按格式线索提供修复入口。多行 YAML 按原始缩进和换行校验，用户打开编辑器时才转换成 JSON。翻译的匹配只检查非空，识别过程在本机完成。[格式识别与导入](../../../crates/rtools/src/plugins/json/core/detect.rs) · [JSON 校验](../../../crates/rtools/src/plugins/json/core/format.rs)

粘贴标签的预览只在接收原文时生成一次。后台同一时间只解析一份原文，解析期间连续粘贴只保留最新一份等候处理。修改标签旁的筛选词复用识别结果。启动器按输入版本丢弃过期结果，同一版本的结果更新时按插件 ID 保留手动选择。识别期间按 Enter 会记住当前确认动作，等当前输入的候选确定后执行一次。更改输入、清除标签或离开列表会取消此前的确认。

## 验收

- 四个插件的五个触发词逐一命中。覆盖大小写、前后空白、中文名称、现有关键词和部分匹配。按 `fy` 打开翻译时原文框中没有新增的 `fy`。
- 单行输入和多行粘贴的合法 JSON 均默认选中 JSON。检查对象、数组、字符串、数字、布尔值和 `null`。交换插件注册顺序，再验证一次。
- 空白输入显示插件列表。半段 JSON 允许继续编辑或打开修复。普通句子可交给翻译。对包含触发词的 JSON，插件接收完整原文。
- 粘贴多行 JSON 后输入 `fy`，验证候选、Enter 和点击都指向翻译并传入原文。反复筛选同一标签只触发一次内容识别。连续替换两次粘贴内容，旧结果和旧的确认动作均不得作用于新内容。
