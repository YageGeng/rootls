# 内置官方主题

## 目标与方案

将 GPUI Kit v0.9.1 官方 `themes/` 中的主题作为编译期资源打包，通过现有 `ThemeRegistry` 在读取设置前加载。保留默认配色；用户在「外观 → 配色」分别选择浅色主题、深色主题，选择立即生效并保存。明暗模式继续支持跟随系统。

采用内置资源，避免安装后依赖工作目录或联网下载。此次不增加用户主题目录、主题编辑器或自动更新。官方资源固定上游提交并保留许可证和来源。

## 实施步骤

1. 在 `assets/themes/` 保存官方主题、许可证和来源；在 `theme.rs` 注册全部内置主题，测试资源可解析、名称唯一、语法配色存在。
2. 在 `Settings` 增加 `light_theme`、`dark_theme`，默认 `Default Light`、`Default Dark`；未知名称或明暗不匹配时回退对应默认主题。测试配置往返、旧配置兼容、主题解析与回退。
3. 在设置页增加两个可搜索的主题下拉框，复用现有控件布局并补齐中英文。整体界面与代码同步变色，保留用户字体、字号和圆角；仅默认主题继续覆盖 JSON key 颜色。
4. 更新 README 和设计文档，运行相关测试、Clippy、修改文件的格式检查，构建 macOS 安装包；验证实际选择和保存。未经明确允许不创建 commit。

## 验证重点

旧配置的显示不变；深浅色主题不能串用；未知主题不丢失其他设置；切换主题后用户字体和字号仍有效；官方主题的语法颜色不被默认主题修正覆盖。

## 验证结果

- 主题资源与回退测试 2 项、设置与本地化测试 15 项通过；Clippy、修改文件格式和脚本语法检查通过。
- macOS 安装包构建、签名验证通过，已更新 `/Applications/rtools.app`。实际窗口出现明暗模式及两个主题选择器，运行日志记录多次主题切换，配置保留用户即时选择；检查时其他偏好未改变。
- 截图接口超时，未逐一目测 38 种配色；Linux / Windows 未实机验证。输入监控授权仍等待用户完成系统密码验证，未将此项计为通过。
