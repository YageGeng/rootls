# 剪贴板历史实施计划

按[已确认的设计](../specs/2026-11-17-clipboard-history-design.md)在当前工作区实施。一个系统复制对应一条有序历史，记录器由主进程持有。SQLite 保存图片原文，平台后端监听和回写，GPUI 插件与设置共享状态。

## 存储与恢复

- [x] 在 `plugins/clipboard/history.rs` 与 `content.rs` 实现有序成员、图片快照、缩略图、子串查询和整组事务。两次复制的顺序不同会保留两条，相同的一组只更新最近位置。
- [x] 验证同名图片、删除原图后重开库、按第二个成员查找、部分缺失与单图复制。整组导出按序号隔离同名文件，清理时保留仍被引用的导出目录。
- [x] 对 1,000 条、512 MiB 双限额按整组淘汰。测试验证了新记录超限或组内成员写入失败时旧数据仍完整。

## 监听与开关

- [x] 在 `plugins/clipboard/platform/` 适配 AppKit、Windows、X11 和 Wayland 的变化通知、原生格式和文件列表。在 macOS 命名剪贴板验证保密标记、过滤自身回写及连续同格式截图。
- [x] 在 `plugins/clipboard/service.rs` 管理启停、在途写入和清空。旧设置默认关闭，插件和分离窗口共用进程级服务。测试覆盖了清空期间已开始读取的记录，以及设置保存失败后的停录状态。

## 界面与验收

- [x] 在 `plugins/clipboard/view.rs` 接入搜索、键盘选择、有序预览、整组及单项复制、删除和清空。更新设置页、注册表、双语文案和使用说明。
- [x] 运行工作区测试、格式和 Clippy 检查。macOS 上用独立命名剪贴板验证实际插件后端，并用 GPUI 离屏窗口检查多图预览、方向键、搜索和取消清空。

2026-11-18，macOS 上工作区测试通过 162 项。两项默认跳过的原生剪贴板测试另行运行，均通过。两项已有单实例测试 `server_round_trip` 和 `a_live_instance_keeps_its_socket` 返回 `EINVAL`，以改动前 HEAD 的单实例代码和测试独立复现。工作区格式与严格 Clippy 均通过。

Windows、Wayland 与 X11 的剪贴板后端已按对应目标单独编译并通过严格 Clippy。完整应用的交叉构建受本机 C 工具链限制。Windows 和 Linux 桌面上的实际粘贴，以及 Finder 或聊天应用的交互粘贴，仍待实机验收。
